This project is a CRUD for a School Schedule System, developed for the evaluation of the Applied Project 2 discipline. In this module, teachers and the subjects they teach are registered.

Este projeto é um CRUD de um sistema de Cronograma Escolar, desenvolvido para a avaliação da disciplina de Projeto Aplicado 2. Neste módulo, são cadastrados os professores e as disciplinas que lecionam.

Este proyecto es un CRUD de un sistema de Cronograma Escolar, desarrollado para la evaluación de la disciplina de Proyecto Aplicado 2. En este módulo, se registran los profesores y las asignaturas que imparten.
