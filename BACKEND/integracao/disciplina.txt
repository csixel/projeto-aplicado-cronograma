para criar uma discplina o backend você precisa enviar os dados dessa forma 
{
  "ds_disciplina": "anan", <<< string
}
rota da API http://localhost:3000/disciplina/criarDisciplina
-----------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------
para deletar uma discplina o backend você precisa enviar os dados dessa forma 
{
  "ds_disciplina": "anan", <<< string
}
rota da API http://localhost:3000/disciplina/deletarDisciplina
-----------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------
para buscar todas as disciplinas cadastradas você deve dar um get nesta rota aqui 
http://localhost:3000/disciplina/buscarTodasDisciplinas
-----------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------
para buscar disciplinas cadastradas pelo nome (caixinha de pesquisa sem utilizar todas as letras) você deve dar um get nesta rota aqui 
http://localhost:3000/disciplina/buscarDisciplinaPeloNome/?q=ana  << informando o parâmetro da buscar no cabeçalho
-----------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------
para modificar uma disciplina cadastrada
http://localhost:3000/disciplina/alterarDisciplina/nome da disciplina aqui
{
  "ds_disciplina": "Matemática II"
}
-----------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------

remove a disciplina do código repassado.

Ex.: http://localhost:3000/disciplina/deletarDisciplina/13

-----------------------------------------------------------------------------------------
-----------------------------------------------------------------------------------------

2) A API de alterar uma disciplina cadastrada, troquei o parâmetro que ela recebe de "String" (era o nome da disciplina), para ser o código da disciplina (cd_disciplina), 
altera a disciplina do código repassado.

Ex.: http://localhost:3000/disciplina/alterarDisciplina/13
{
  "ds_disciplina": "Novo nome da disciplina"
}
